# 任务 0021：迁移后的备份读数不对

用户从 v1 版本备份恢复数据后，报表全是 0；按日期筛选还会直接报错。

现有代码只处理当前版本（v2）的快照。恢复入口在 `api.load()`，
它需要同时接受 v1 和 v2 两种格式。

约束：

- v1 的数量字段叫 `q`，时间 `ts` 是 `"YYYY-MM-DD"` 字符串；v2 是 `qty` 与 Unix 秒（int）；
- 迁移要幂等：同一份数据迁移两次，结果一致；
- `report()` 在恢复后必须给出正确数量（含负数，负数表示退货）；
- `report_as_of(store, ts)` 必须能对恢复后的数据按时间过滤；
- 只能改源码，不能改 `test_ledger.py`；
- 改完必须跑一次 `run_tests` 确认，全绿后调用 `finish`。
